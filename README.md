# Advanced Styling and JavaScript Portfolio 🚀

A modern, responsive, and interactive web development portfolio built to demonstrate advanced CSS styling and complex Vanilla JavaScript functionalities. 

## 🌟 Features

### Core Functionalities
* **Fully Responsive Design:** Adapts flawlessly to mobile, tablet, and desktop screens using CSS Flexbox, Grid, and media queries.
* **Interactive Image Carousel:** Features auto-sliding images, manual navigation (Next/Prev buttons), and clickable dot indicators with smooth transitions.
* **Dynamic Quiz Application:** A 5-question developer knowledge quiz with real-time score tracking, dynamic option rendering, and result calculation.
* **Live API Integration:** Fetches and displays random programming jokes from the public Official Joke API with loading states and error handling.

### Bonus Features Included
* **🌙 Dark / Light Mode Toggle:** User preference is saved across sessions using `localStorage`.
* **🏆 High Score Tracking:** The quiz saves the user's highest score in the browser's `localStorage`.
* **✨ Scroll Reveal Animations:** Elements smoothly fade and slide into view as the user scrolls down the page.
* **📱 Mobile Navigation:** A sleek hamburger menu that slides in for smaller screens.

## 🛠️ Technologies Used

* **HTML5:** Semantic structuring.
* **CSS3:** Custom variables, Flexbox, Grid, keyframe animations, and media queries.
* **Vanilla JavaScript:** ES6+ syntax, DOM manipulation, asynchronous `fetch` API, and LocalStorage (No frameworks used).
* **External Assets:**
    * [Google Fonts (Poppins)](https://fonts.google.com/specimen/Poppins)
    * [Font Awesome Icons](https://fontawesome.com/)
    * [Official Joke API](https://official-joke-api.appspot.com/)
